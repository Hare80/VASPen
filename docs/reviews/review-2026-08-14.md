# Code Review — 2026-08-14

First layered review of the v0.1 codebase (~11.7k lines source, 529 tests).
Method: 4 parallel review agents (core physics / core data safety / UI routing /
viewport+editors) plus a light sweep of the remaining files; every finding was
then adversarially re-verified against the code before fixing. Fixes landed
with regression tests (suite grew to 567 tests, all green).

Legend: **fixed** = patched + regression test; **kept** = verified not a bug
or deliberate design; **deferred** = recorded, deliberately untouched.

### Verified not bugs (kept as-is)

- `builder.make_supercell` block-major tile order; `sort_atoms` stable permutation.
- `mic_vector` degenerate-cell path (viewport passes `np.eye(3)` for rank<3).
- Undo snapshots have no object aliasing; redo loops cannot grow the stacks.
- `suggest_band_path` basis transform (verified numerically on a BCC
  conventional cell); INCAR renderer alignment, presets, KPOINTS line-mode
  contents all match CLAUDE.md §8.
- `interpolate_neb`/`interpolate_idpp` frozen semantics; `ws_minimal_image`
  converges to the lattice global minimum.
- The never-emitted `bond_removed` signal and its MainWindow listener were
  dead code — removed as cleanup.
- Symmetry: molecules in a periodic box go through the spglib space-group
  branch — consistent with §7.5 `is_periodic` semantics.
