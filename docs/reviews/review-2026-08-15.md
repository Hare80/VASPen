### Documented (kept as-is)

- **Per-termination c-length variance**: two shifts of the same cleave can give
  different material extents (raw pymatgen behavior — the shift's wrap
  position changes the extremal planes, e.g. 19.83 vs 16.03 Å on the pattern
  cell). `_standard_slab_cell` faithfully applies c = extent + exact vacuum,
  so the requested vacuum is exact in every case. Spec-compliant; recorded.
- **Rebox vacuum range 0.5–100 Å** vs wrap 0.5–50: intentional (re-applied
  slab vacuum can be larger than molecule padding). Recorded in CLAUDE.md.
- **bonds.py cap mechanism**: the 1000-atom cap itself is correct and stays;
  only the docstring's memory-attribution was rewritten.

### Verified not bugs (kept as-is)

- All three `total`/`item`/`done` slots generation-guarded; total always
  precedes its items; stale generations never touch `_busy`/OK; OK enabled iff
  not busy and a real slab is selected.
- `_notify` RuntimeError guard; holder lifetime; QRunnable auto-deletion.
- MenuButton `setItemText` semantics (never emits, keeps action identity,
  popup and selection); index clamping on menu rebuild; no QComboBox anywhere.
- `_plane_data` port fidelity: shifts byte-equal to pymatgen's internal
  enumeration on all six test structures (incl. boundary-straddling clusters).
- `_standard_slab_cell`/`_unwrap_layers`/`rebox_slab` distance preservation:
  MIC multiset identical to ≤8e-15 Å; unwrap is a perfect no-op on dense
  6-layer Cu(111) with 2 Å vacuum.
- Rebox flag/magmom 1:1 carry (atom order never changes); primitive
  symmetrize is a pure rotation (distances preserved); frozen guard on
  symmetrize; double-open raise; last-closes pause/resume both directions.
- Supercell change re-displays without recompute; cache-key short-circuit.
- bonds cap callers treat `[]` as "no auto bonds" cleanly (viewport auto-
  detect, NEB frame bonds, manual bonds unaffected).
- zh.ts placeholder integrity (522 messages checked): zero mismatches; no
  positional-format risks in the changed files.

### termination_labels gate results (function deleted — recorded for the record)

pymatgen 2026.5.4, layers=4, vacuum=15:

| Structure | miller | labels | built slabs | Match |
|---|---|---|---|---|
| Cu conv fcc | (111)/(100) | Cu4 / Cu2 | Cu | no |
| MgO conv | (100)/(111) | Mg2O2 / Mg4 | MgO / Mg | no |
| GaAs conv | (111)/(100) | Ga4 / Ga2 | Ga | no |
| Cu 2×2×2 | (111)/(100) | Cu16 / Cu8 | Cu | no |
| SrTiO3 2×2×2 | (100) | Sr4O4 | SrO | no |
| SrTiO3 conv | (100)/(110) | matches | — | **yes** |
| pattern cell ±0.03 Å / straddle | (001) | Al11O11 | O11/Al11 | no |

Only structures whose ouc in-plane cell is already primitive match — the
rule, not an accident. The mismatch sources: ouc in-plane multiplicity,
primitive reduction in `get_slab`, and the 0.1 Å cluster vs round-3dp+0.49
tolerance scales.
