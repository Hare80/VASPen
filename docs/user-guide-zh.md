# VASPen 用户指南

## 1. 简介

VASPen 是面向 [VASP](https://www.vasp.at) 第一性原理计算的跨平台桌面
图形界面。它提供三维结构的可视化建模、表面/解理表面构建、VASP 四件输入
文件(POSCAR、INCAR、KPOINTS、POTCAR)的生成,以及 NEB(微动弹性带)
工作流——覆盖从"我有了一个晶体结构"到"我可以提交作业"之间的全部
环节。

v0.3.0 是首个打包发布的 Windows 版本。VASPen 免费开源(MIT 许可),
源代码位于 <https://github.com/Hare80/VASPen>。

## 2. 系统要求

**Windows 发行版(推荐):**

- Windows 10 或 11,64 位
- 约 1 GB 空闲磁盘空间(解压后的完整体积)
- 支持 OpenGL 3.3 的显卡驱动(近十年内的任何驱动均可)
- 无需安装 Python——发行包自包含

**从源码运行**(开发者、Linux 用户):

- Python ≥ 3.11
- PySide6 ≥ 6.6、ASE ≥ 3.29、pymatgen ≥ 2024.1、spglib ≥ 2.3、
  NumPy ≥ 1.26、SciPy ≥ 1.12
- 参见仓库 `README.md`

## 3. 下载与运行

1. 打开 <https://github.com/Hare80/VASPen/releases>,下载
   `VASPen-v0.3.0-win64.zip`。
2. 解压到任意位置,得到一个 `VASPen/` 文件夹,内含 `VASPen.exe` 和
   `_internal/` 文件夹。**`VASPen.exe` 与 `_internal/` 必须放在一起**——
   单独移动 exe 会导致程序无法启动。
3. 双击 `VASPen.exe`。

说明:

- 免安装、无注册表依赖——绿色便携软件。更新 = 替换整个文件夹。
- 设置(语言、主题、最近文件)保存在程序文件夹之外,更新后依然
  保留。
- exe 未做代码签名。首次运行时 Windows SmartScreen 可能提示:
  点击**更多信息 → 仍要运行**。请只从官方 GitHub 仓库下载。
- Linux:请从源码运行(见 §2);发行 zip 仅限 Windows。

## 4. 快速上手

1. **配置赝势库**(仅 POTCAR 生成需要):编辑 → 首选项 → *赝势库* →
   设置库根路径(见 §13.3)。
2. **打开结构**:文件 → 打开,或将结构文件拖入窗口。源码仓库的
   `examples/` 文件夹附带示例结构。
3. **三维浏览**:左键拖动旋转,右键拖动平移,滚轮缩放。
4. **构建解理表面**:工具 → 解理表面 → 选择 Miller 指数、层数与真空 → 确定
   (见 §8)。
5. **生成输入文件**:计算 → 生成全部输入文件 → 选择任务(如 SCF)→
   设置输出目录 → **生成**。四个文件写入该目录(见 §13)。

## 5. 界面导览

### 菜单

| 菜单 | 内容 |
|------|------|
| **文件** | 新建结构 (Ctrl+N)、打开 (Ctrl+O)、保存 (Ctrl+S)、另存为 (Ctrl+Shift+S)、导出为 POSCAR、最近文件(10 条,可清空)、退出 |
| **编辑** | 撤销 (Ctrl+Z)、重做 (Ctrl+Y / Ctrl+Shift+Z)、全选 (Ctrl+A)、取消全选、反选、选择邻居、选择连通、冻结、解冻、键级(单键/双键/三键/芳香键)、自动检测键(默认关闭)、首选项 |
| **视图** | 重置视图、显示样式(球棍模型 / 空间填充 (CPK) / 线框)、显示晶胞、原子标签、显示选项、语言(English / 中文)、停靠面板开关(结构 / 测量 / 属性) |
| **计算** | 生成 INCAR、生成 KPOINTS、生成 POTCAR、生成全部输入文件 |
| **工具** | 解理表面、超胞、包裹为周期晶胞、重新装箱、编辑晶格、查找对称性 |
| **帮助** | 关于 VASPen、关于 Qt |

**外部修改自动重载**:加载文件后,VASPen 会在磁盘上监视该文件。若其他
程序(文本编辑器、脚本、或 VASPen MCP 服务器)修改了它,视图会自动重载;
若你有未保存的修改,VASPen 会先询问——重载会丢弃这些修改。

### 工具栏

- **主工具栏**:新建、打开、保存、生成全部、解理表面、超胞、重置视图。
- **编辑工具栏**:选择、添加原子(元素快捷键 + 完整元素周期表选择器)、
  移动、旋转、删除、创建键、冻结、解冻、检测键、距离、角度、二面角、
  视角方向(前/后/左/右/上/下)、撤销、重做。

### 停靠面板与状态栏

- **结构树**(左侧):原子列表与晶胞参数,与选择状态同步。
- **测量**(右侧):距离/角度/二面角测量列表。
- **属性**(右侧):单个原子的元素、位置、冻结标志、磁矩 (MAGMOM) 与
  组分,以及电荷/受力/速度显示。
- **状态栏**:原子数与化学式,晶胞参数 a/b/c/α/β/γ。

任何关闭的停靠面板都可以从视图菜单重新打开。

### 欢迎页

未加载结构时显示欢迎页:最近文件列表与新建结构 / 打开 / 浏览按钮。
**单击选中最近文件,双击(或回车)打开**;"打开"打开选中的最近文件;
"浏览"打开标准文件对话框。任何时候都可以把文件拖入窗口直接打开。

## 6. 三维视图

| 鼠标 | 操作 |
|------|------|
| 左键拖动 | 旋转视角 |
| 右键拖动 / 中键拖动 | 平移 |
| 滚轮 | 缩放——完全自由:相机可以穿过原子和晶胞边框;原子靠近相机时会渐隐 |
| 单击原子 | 选中 |
| Ctrl/Shift + 单击 | 加选/减选 |
| Shift + 拖动(选择模式下) | 框选原子 |
| Esc | 取消进行中的移动/旋转操作 |

其他说明:

- 采用**正交投影**(无透视变形)。
- **打开时的默认视角**:周期结构以 c 轴朝上俯视(b 向上,a 向左);
  分子以 45°/30° 等轴视角显示。
- **重置视图**(工具栏 / 视图菜单)重新适配相机。
- 就地编辑(超胞、解理表面、增删原子)保留相机视角。
- 视图菜单可开关晶胞边框、原子标签与显示样式;"显示选项"打开渲染
  设置对话框(颜色、背景、原子半径),实时预览。
- 点击已存在的键显示其键长;测量工具(距离/角度/二面角)向测量面板
  添加条目。

## 7. 结构编辑

编辑工具位于编辑工具栏(或编辑菜单)。点击工具即激活;点击"选择"
(或按 Esc)回到浏览状态。

| 工具 | 功能 |
|------|------|
| 选择 | 单击/框选原子;全选、取消全选、反选、选择邻居、选择连通在编辑菜单中 |
| 添加原子 | 选择元素(快捷键或完整元素周期表选择器),在视口中点击放置 |
| 移动 | 拖动选中的原子到新位置 |
| 旋转 | 旋转选中的原子 |
| 删除 | 点击原子将其删除(Delete 键同样有效) |
| 创建键 | 依次点击两个原子添加键;键级(单键/双键/三键/芳香键)在编辑菜单设置 |
| 冻结 / 解冻 | 切换选中原子的 VASP 选择性动力学标志(三个方向)。冻结原子不可移动,写入 POSCAR 时带 `F F F` 标志 |
| 检测键 | 对当前结构做一次性键检测 |
| 自动检测键 | (默认关闭)每次编辑后重新检测键;超过 1000 原子的结构跳过自动检测 |

说明:

- **撤销/重做**(Ctrl+Z / Ctrl+Y)覆盖结构编辑,每步一个撤销节点。
- **属性**面板显示选中原子的元素、位置(周期结构显示分数坐标)、
  冻结标志与磁矩。设置 MAGMOM 后,生成的 INCAR 自动启用
  `ISPIN = 2`(见 §13.1)。
- **编辑晶格**(工具菜单)实时预览修改晶胞参数;仅周期结构。
- **超胞**(工具菜单)按 (n₁, n₂, n₃) 扩胞。
- 支持部分占位(无序)结构;会丢弃无序信息的操作(如对称化、解理表面)
  会先征求确认。

## 8. 解理表面

工具 → **解理表面** 从**块体周期结构**构建 slab(当前结构不符合条件时
对话框会说明,并指向适用于已含真空结构的"重新装箱")。

1. 输入 **Miller 指数** (hkl)。
2. 选择**层数**与**真空厚度**。
3. 终止面列表在后台计算(对话框非模态——计算期间仍可旋转视角;点击
   某个终止面可将其插队到计算队列最前)。
4. 选择一个终止面(每个都会在三维视口中预览),点击确定。

得到的 slab 为正交盒:c 轴严格沿表面法线方向,真空厚度精确,slab 居中。
作为一个撤销步应用;另存为新文件。若 slab 含部分占位,会先询问是否
丢弃无序信息。

## 9. 重新装箱

工具 → **重新装箱** 为**已含真空**的结构(例如编辑过的 slab,或导入
时真空不合适)沿 c 轴重新施加真空。面内晶胞、原子顺序、冻结标志与
磁矩全部保留——不同于解理表面(解理表面会构建新的原子集合)。真空范围
0.5–100 Å(默认 15 Å,带"记住"选项)。一个撤销步。

## 10. 对称性

工具 → **查找对称性** 分析结构(空间群或分子点群),并提供:

- **对称化**——将结构贴合到理想对称位置。
- **惯用晶胞**——标准化为惯用晶胞(默认选项)。
- **原胞**——约化为原胞,采用标准取向(a 沿 x,b 在 xy 平面内)。

晶胞转换仅限周期结构。结果作为一个撤销步应用,另存为新文件。

## 11. 包裹为周期晶胞

分子(无周期晶胞)不能直接保存为 VASP/CIF 格式。VASPen 自动处理:

- **保存**分子为周期格式(或运行"生成全部输入文件")时弹出包裹
  对话框:选择真空层厚度(0.5–50 Å,默认 5 Å,带"记住"选项)。分子
  居中放入立方盒,每个面恰好留出所设真空。
- 工具 → **包裹为周期晶胞** 可主动执行同样的步骤。

包裹操作可撤销,并保留相机视角。

## 12. NEB 工作流

计算 → 生成全部输入文件 → 计算类型 = **NEB**。

1. 在 POSCAR 页分别浏览选择**初态**与**末态**结构。两者原子数与
   元素必须相同、晶胞必须一致(变胞 NEB 会被明确拒绝)。
2. 对话框显示路径长度(Å)。建议镜像数 = `ceil(距离 / 0.8 Å)`;
   可设置 1–98 个镜像。
3. 选择插值方式:
   - **Linear**(默认)——分数坐标下按最小镜像位移逐原子线性插值。
   - **IDPP**——弛豫各镜像使相邻镜像间的原子间距变化均匀,原子不会
     互相穿过。当线性路径会发生原子碰撞(如旋转基团)时优先选择。
4. 点击**插值**,生成镜像列表;点击某一帧可在三维视口中预览。
5. **冻结原子**(初态结构的选择性动力学标志):完全冻结的原子在
   *每一*帧中保持初始位置,写出的每个 POSCAR 都携带标志。若冻结
   原子在末态位置不同,插值会被阻断并提示。部分冻结的原子正常插值
   (其标志由 VASP 在运行时执行)。
6. **帧编辑**:点击*中间*帧进入编辑模式——可以移动/旋转该帧的原子、
   编辑键(逐帧撤销/重做)。初末帧锁定;帧内原子不可删除。再次点击
   插值会询问是否放弃手动编辑。
7. INCAR 页自动填入 NEB 预设(含 `IMAGES`)。
8. 生成时在所选输出目录写出 `00/POSCAR` … `0N/POSCAR` 子目录及
   INCAR / KPOINTS / POTCAR——标准 VASP NEB 运行布局。

现成的初末态结构对见 `examples/neb_*` 各文件夹。

## 13. 生成 VASP 输入文件

计算 → **生成全部输入文件** 是一站式对话框:顶部任务选择器联动
POSCAR/INCAR/KPOINTS/POTCAR 四个页签(之后仍可手动覆盖)。只有点击
**生成** 时才写文件,写入对话框中选择的输出目录。独立的生成
INCAR / KPOINTS / POTCAR 对话框使用同样的面板。

### 13.1 INCAR 预设

| 标签 | SCF | 结构优化 | 能带 | DOS | 光学 |
|------|-----|----------|------|-----|------|
| ENCUT | 400 | 400 | 400 | 400 | 400 |
| ISMEAR | 0 | 0 | 0 | −5 | 0 |
| SIGMA | 0.05 | 0.05 | 0.05 | 0.05 | 0.01 |
| EDIFF | 1E-6 | 1E-6 | 1E-6 | 1E-6 | 1E-6 |
| EDIFFG | — | −0.01 | — | — | — |
| IBRION | — | 2 | — | — | — |
| ISIF | — | 3 | — | — | — |
| NSW | — | 100 | — | — | — |
| ISPIN | 1 | 1 | 1 | 1 | 1 |
| LORBIT | — | — | — | 11 | — |
| NEDOS | — | — | — | 2001 | 2000 |
| LOPTICS | — | — | — | — | T |
| CSHIFT | — | — | — | — | 0.1 |

能带:预设 `ICHARG = 11`、`LCHARG = T`——能带计算读取前一步 SCF 计算
写出的 CHGCAR(SCF 预设默认 `LCHARG = F`,请在那里改为 T)。

NEB 预设(VTST 风格):SCF 基础之上加 `EDIFFG = -0.02`、
`IBRION = 3`、`POTIM = 0`、`IOPT = 1`(LBFGS)、`ICHAIN = 0`、
`NSW = 500`、`SPRING = -5`、`LCLIMB = .TRUE.`。`IMAGES` 初始为空、
必须填写(NEB 任务自动填入;两条生成路径都会拒绝未填的必填标签)。

提示:

- 需要时把 `ENCUT` 提高到 POTCAR 中最大 `ENMAX` 的 1.3 倍。
- 生成的每一行都带对齐的注释;建议但未启用的行(`# MAGMOM`、
  `# IVDW = 11`、`# ISTART = 1`)在空行之后,取消注释才生效。
- 预览面板与写文件用的是同一个渲染器——所见即所得。

### 13.2 KPOINTS 模式

| 模式 | 关键参数 | 默认 |
|------|----------|------|
| 自动 | 间距(2π/Å 约定) | 绝缘体 0.04,金属 0.03(精细 0.02,粗略 0.05) |
| 手动网格 | n₁ n₂ n₃ | 自行指定 |
| 线模式(能带) | 高对称路径、每段点数 | 20 点/段 |

自动模式写出显式的规则网格(Γ 中心或 Monkhorst-Pack,平移 0 0 0),
密度对应所选间距(2π/Å 单位)。能带任务自动切换到线模式,并按结构
对称性预填合适的高对称路径(回退路径:`G-X|X-M|M-G`)。

非周期结构没有 k 网格:自动模式预览显示提示,且生成被阻止,直到结构
被包裹为周期晶胞(§11)。

### 13.3 POTCAR

先在首选项中配置库根路径。期望的目录布局是标准 VASP 赝势库:

```
<库根路径>/
  potpaw_PBE.54/   (或 PBE.54/ 等)
    Fe/
      POTCAR
    O/
      POTCAR
```

对话框提供泛函选择器(**PBE** 为默认;可选 PBE_new、LDA、PW91),并
按元素预选推荐变体(需要半芯电子的元素用 `_d` / `_sv` 变体);备选
变体直接从你的库中读取。选中的 POTCAR 按 POSCAR 元素顺序拼接。赝势
库**不随** VASPen 分发——请使用自己合法获得的 VASP 势文件。

### 13.4 POSCAR

默认写 **Fractional (Direct)** 坐标(首选项可切换为 Cartesian)。
冻结原子带 `Selective dynamics` 行,标志为 `F F F` / `T T T`。

## 14. 设置

编辑 → **首选项**:

| 设置项 | 含义 |
|--------|------|
| 语言 | English / 中文——即时切换(也可从视图 → 语言切换) |
| 主题 | 浅色 / 深色——即时切换 |
| 默认计算类型 | 预填生成对话框的任务选择器 |
| POSCAR 坐标 | Fractional (Direct) 或 Cartesian |
| 赝势库根路径 | VASP 库路径(见 §13.3) |

设置保存在程序文件夹之外(Windows 下为注册表),更新后依然保留。

## 15. 支持的格式

读写支持:CIF、XYZ、EXTXYZ、POSCAR/CONTCAR(任意大小写,无扩展名
文件可识别)、XSF、PDB、JSON、CUBE、TRAJ、DB。

- 将**分子**保存为 VASP/CIF 会触发周期包裹对话框(§11)。
- 将**部分占位**结构保存为 POSCAR 会先征求确认(POSCAR 无法表示
  无序)。
- CIF 读取会消毒未知占位标记与无效空间群头——外部建模软件导出的
  "未知群号"文件也能正常打开。

## 16. 示例

源码仓库附带精选的 `examples/` 文件夹:

- **结构文件**:fcc Cu 原胞(对称性转换)、bcc Fe 2×2×2(自旋 INCAR)、
  hcp Mg、金刚石(能带/DOS)、NaCl 岩盐((100) 解理表面、双元素 POTCAR)、
  GaAs 闪锌矿(能带路径)、ZnO 纤锌矿、TiO₂ 金红石、BaTiO₃ 钙钛矿
  (三元素 POTCAR、极性终止面)、MFI 分子筛 288 原子(大晶胞渲染)、
  Cu (111) slab、3×3 石墨烯、苯分子(包裹流程)、PZT 无序钙钛矿
  (CIF 占位信息)。
- **NEB 初末态对**:乙烷旋转(Linear 与 IDPP 对比)、Au(111) 空位跳跃
  (冻结 slab)、P–O–H 吸附迁移。

每个 NEB 文件夹自带 README,含分步操作说明。

## 17. 常见问题

**Windows SmartScreen / 杀毒软件报警。**
发行包未做代码签名,Windows 首次运行会提示(更多信息 → 仍要运行),
部分杀毒软件对未签名下载敏感。请只从官方 GitHub 仓库下载,并核对
发行说明中公布的 SHA-256 校验和。

**首次启动很慢。**
一次性开销:Windows/杀毒软件在扫描体积较大的程序包。之后的启动
都很快。

**生成的文件在哪里?**
在对话框中选择的输出目录——点击"生成"之前不会写任何文件。

**提示"未找到赝势库"。**
在编辑 → 首选项 → 赝势库中设置库根路径(§13.3)。

**INCAR 页提示某个标签没有值(NEB)。**
`IMAGES` 必须填写。NEB 任务下插值后会自动填入。

**原子无法移动。**
它被冻结了(选择性动力学)。先解冻(编辑 → 解冻,或工具栏解冻按钮)。

**显示的是欢迎页。**
没有加载结构。打开一个文件,或点击"新建结构"进入空白工作区。

**三维视图黑屏/显示异常。**
更新显卡驱动;VASPen 需要 OpenGL 3.3。

**界面语言不是想要的。**
视图 → 语言 可在 English 与中文之间即时切换。

**如何更新?**
下载新的 zip,替换整个 `VASPen/` 文件夹。设置保存在文件夹之外,
不受影响。

**需要报告问题。**
请附上日志文件 `%LOCALAPPDATA%\VASPen\vaspen.log`(仅 Windows 发行
版会写日志)。

**Linux 呢?**
请从源码运行(见 §2)。发行 zip 仅限 Windows。

## 18. MCP 服务器(供 AI 客户端使用)

VASPen 内置无头 [Model Context Protocol](https://modelcontextprotocol.io)
(MCP)服务器,让 AI 助手——Claude Desktop、ZCode、Cursor 及其他 MCP
客户端——直接调用本工具箱:从对话中加载并分析结构、切面、建超胞、
准备 NEB 计算并一次性生成全套 VASP 输入文件。

### 18.1 安装

- **源码运行**(Windows 与 Linux):`pip install -e ".[mcp]"`,之后即有
  `vaspen-mcp` 命令(`vaspen-mcp --version` 可查看版本)。
- **发行压缩包**(Windows):使用以 `--with-mcp` 构建的压缩包中的
  `VASPen/vaspen-mcp/vaspen-mcp.exe`。

服务器是纯 stdio 进程:由 AI 客户端按需启动,通过 stdin/stdout 交换
JSON-RPC,不监听任何网络端口。

### 18.2 客户端配置

Claude Desktop(`claude_desktop_config.json`)或 ZCode / Cursor 的 MCP
设置:

```json
{
  "mcpServers": {
    "vaspen": {
      "command": "D:/path/to/vaspen-mcp.exe",
      "args": []
    }
  }
}
```

源码安装时 `"command": "vaspen-mcp"` 通常即可。

### 18.3 AI 能做什么

| 分组 | 工具 |
|------|------|
| 结构 | open_structure、get_structure_info、list_atoms、save_structure、make_periodic |
| 编辑 | make_supercell、set_fixed_atoms、set_magmoms、translate_atoms、rotate_atoms |
| 分析 | measure(距离/键角/二面角)、find_bonds、analyze_symmetry、suggest_band_path、estimate_k_mesh |
| 对称性与表面 | symmetrize_cell、list_slab_terminations、cut_surface、rebox_slab |
| VASP 输入 | list_incar_presets、generate_inputs |
| NEB | neb_check、neb_setup |
| 可视化 | render_preview——生成球棍模型图片,AI 可以直接查看 |
| 逃生舱 | run_python——对当前结构执行 Python(可在设置中关闭) |

典型指令:*"打开 TiO2_rutile.vasp,告诉我空间群,然后在 ./vasp-run 生成
一套 k 间距 0.03 的 SCF 输入文件"*——助手会自行调用相应工具并汇报结果。

### 18.4 注意事项

- 无论界面语言为何,工具响应均为英文。
- 原子索引从 0 开始;长度单位为 Å,角度单位为度。
- **设置 → 赝势库路径**在 GUI 与 MCP 服务器之间共享(赝势库本身永不
  打包分发)。
- 需要确认的操作与 GUI 的确认对话框一一对应:AI 必须显式传
  `allow_disorder_loss`(丢弃部分占位)或 `force`(忽略 NEB 原子顺序
  警告)等确认参数,不会有静默的破坏性操作。
- 当服务器写入的文件正被 GUI 打开时,GUI 会察觉并重载(有未保存修改时
  会先询问)——见"菜单"一节的自动重载说明。
