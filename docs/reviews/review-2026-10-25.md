# Code Review — 2026-10-25

Full review of everything committed after the v0.3 release:
**20 commits** (origin/main..HEAD), 41 files, **+3218/−676** (MCP project
tools incl. neb_setup run_name + delete_run; run editor §7.15 P1.7; GUI
run creation + NEB endpoint pickers + run deletion §7.15 P2; POTCAR
per-element display + variant preservation; welcome-page projects section;
main-window resize fix; publish-isolation §7.16).

Method: 4 review agents (MCP layer / core layer / UI layer / tests+i18n+docs)
— two completed, two exceeded the concurrency limit and were replaced by an
adversarial self-review against the same checklists. Every finding was
re-verified against the code (several with live repros: phantom-run
registration, traversal guard bypass, bridge double-delivery, real-registry
pollution) before fixing. Fixes landed with regression tests — suite grew
**836 → 852**, all green.

Legend: **fixed** = patched + regression test; **kept** = verified not a bug
or deliberate design; **documented** = recorded, deliberately untouched.

## Findings

### High

| # | Location | Issue | Status |
|---|----------|-------|--------|
| 1 | tools.py `create_run` | The neb preset ships `IMAGES = ""`; `generate_all_inputs` refuses blank tags — the most natural call, `create_run(name, preset="neb")`, registered the run and THEN failed, leaving a phantom manifest entry (verified live) that also burned a run number per retry. Same shape in `neb_setup` run_name mode (endpoints + add_run before frames) | **fixed**: create_run refuses neb-without-IMAGES up front with a pointer to neb_setup; BOTH tools roll the registration back (`remove_run(force=True)`) when any post-registration step raises. Tests: clean-error + no-number-burned; rollback for create_run and neb_setup (bad potcar_library) |
| 2 | run_editor.py geometry / tests | `RunEditorDialog` constructed `QSettings("VASPen","VASPen")` directly, bypassing the suite's `isolated_config` isolation — every run-editor test wrote its geometry into the developer's REAL registry (a bogus 400×798 value was found in HKCU; pytest-qt teardown fires closeEvent even on hidden dialogs) | **fixed**: `AppConfig.qt_settings()` accessor (documents the rule); run_editor routes through it; the stale registry value deleted. Isolation now automatic via conftest's `_instance` rebind |
